NonconvexInteriorPoint.BarrierSelection — Type
BarrierSelection

Selects which constraints enter the barrier of IPMAlg and with which barrier type (mirroring the constraint-relaxation selections of the ecosystem):

  • ineq = false: inequality constraints are excluded from the barrier and enforced as hard slacked constraints (c_I(x) + s = 0) — the per-category counterpart of slacks = true;
  • box = false: variable bounds are excluded from the barrier (and not enforced);
  • sd = false: semidefinite/set constraints are excluded from the barrier (and not enforced — use with care);
  • labels: constraints carrying any of these labels are excluded from the barrier (inequalities become slacked, sets are not enforced);
  • ineq_type: :log (-ln t), :inv (1/t) or :quad (1/(2t²)) scalar barrier on the inequality slacks;
  • box_type: the same for the bound distances;
  • sd_type: :logdet (-log det X, the default), :inverse (tr(X⁻¹)) or :inverse_square (tr(X⁻²)/2) for the semidefinite barriers (implemented by NonconvexSemidefinite for the dense oracle; the matrix-free and trace oracles support :logdet).
NonconvexInteriorPoint.IPMAlg — Type
IPMAlg

A barrier interior-point method for smooth, generally nonconvex nonlinear programs: box bounds, inequalities and set constraints (including PSDCone) enter a log-barrier objective (slacks derived exactly, keeping the iterates on the central path), while equality constraints are enforced through the KKT system with an inertia-correction loop. Evaluation strategies are selectable per constraint via NonconvexCore labels (IPMEvaluationSelection). Options are set with IPMOptions.

NonconvexInteriorPoint.IPMEvaluationSelection — Type
IPMEvaluationSelection

Selects the evaluation strategy of individual constraints through NonconvexCore's label mechanism (flags): a constraint whose flags intersect matrixfree is evaluated matrix-free (implicit products, iterative solves, no dense assembly), and a constraint whose flags intersect trace is evaluated with randomized trace estimation (implies matrix-free). The _all flags select every constraint. An explicit label selection dominates the _all flags; trace dominates matrixfree; unselected constraints use the dense strategy.

NonconvexInteriorPoint.IPMModel — Type
IPMModel

The flattened interior-point model: objective, box bounds, nonlinear equalities and (per-constraint barrier-masked) inequalities, native linear equality/inequality blocks with cached Jacobians, and barrier set constraints (PSD cones). Built from a NonconvexCore VecModel by build_ipm_model; the masks nlineq_barrier/lin_ineq_barrier record which inequalities enter the barrier (true) and which are slacked (false).

NonconvexInteriorPoint.IPMOptions — Type
IPMOptions

Options for IPMAlg, constructed with keyword arguments (IPMOptions(; tol = 1e-8, mu_init = 0.1, ...)).

Keywords

  • tol::Real = 1e-8: primal and (scaled) dual feasibility tolerance.
  • mu_init::Real = 0.1: initial barrier parameter.
  • mu_min::Real = 1e-11: terminal barrier parameter.
  • mu_linear_decrease_factor::Real = 0.2: linear μ decrease factor.
  • mu_superlinear_decrease_power::Real = 1.5: superlinear μ decrease power.
  • theta_mu::Real = 1.5: switch to the superlinear μ update when the barrier KKT error drops below theta_mu * μ.
  • max_iter::Int = 3000: maximum number of iterations.
  • linear_solver::Symbol = :auto: :auto (Krylov if any matrix-free or trace-estimated constraint is present, dense otherwise), :direct (assembled symmetric KKT, requires no matrix-free/trace constraints) or :krylov (preconditioned MINRES on the augmented KKT).
  • slacks::Bool = false: when true, inequality constraints are rewritten with explicit slack variables (c_I(x) + s = 0, s ≥ 0, slack barrier -μ Σ ln sᵢ), matching the Ipopt-style slacked formulation; when false (the default), inequalities and PSD constraints enter the log barrier directly, their gradients are assembled from adjoints (no Jacobians are materialized), and only the equality constraints contribute Jacobians to the KKT system.
  • barrier::BarrierSelection = BarrierSelection(): which constraints enter the barrier and with which barrier type (see BarrierSelection).
  • inner::Union{Nothing,NonconvexCore.AbstractOptimizer} = nothing: an optional inner optimizer used to solve each barrier subproblem (any NonconvexCore optimizer); nothing uses the built-in Newton solver.
  • inner_options = nothing: options for the inner optimizer.
  • inner_max_iter::Int = 50: maximum Newton iterations per barrier subproblem for the built-in inner solver.
  • evaluation::IPMEvaluationSelection = IPMEvaluationSelection(): per-label evaluation strategy selection.
  • krylov_tol::Real = 1e-8: relative tolerance of the Krylov KKT solve.
  • krylov_maxiter::Int = 200: maximum Krylov iterations per KKT solve.
  • trace_nprobes::Int = 10: number of Hutchinson/SLQ probes.
  • trace_lanczos_deg::Int = 30: Lanczos degree in stochastic Lanczos quadrature.
  • trace_method::Symbol = :slq: log-determinant estimation method for :trace-labeled PSD constraints — one of :slq (stochastic Lanczos quadrature), :chebyshev, :hutchpp, :rational, :taylor, :integration, :lowrank (see NonconvexSemidefinite.logdet_estimate).
  • trace_cg_tol::Real = 1e-6: conjugate-gradient tolerance for X⁻¹v solves.
  • trace_final_exact::Bool = false: switch trace-estimated constraints to the exact oracle for the final barrier iterations.
  • linear_constraints::Bool = true: detect and handle linear constraints natively with cached constant Jacobians (structural LinearFunction detection plus a Jacobian-constancy probe).
  • bound_relax_factor::Real = 1e-8: relative relaxation of the variable bounds at initialization.
  • relaxed_labels = nothing: Symbol, vector of Symbols, or nothing; constraints carrying any of these labels are moved from hard constraints into a quadratic penalty (relaxation).
  • relaxed_penalty_rho::Real = 1e4: penalty weight for relaxed constraints.
  • tau::Real = 0.995: fraction-to-the-boundary parameter.
  • s_min::Real = 1e-8: minimum slack/bound distance kept by fraction-to-the-boundary.
  • max_time::Real = Inf: time limit in seconds.
  • verbose::Bool = false: print iteration information.
  • rng::Random.AbstractRNG = Random.default_rng(): random number generator for the trace estimators.
NonconvexInteriorPoint.IPMResult — Type
IPMResult

Result returned by optimize with IPMAlg.

Fields

  • minimizer: the best primal solution found,
  • minimum: the objective value at minimizer,
  • status: Symbol summarizing the outcome — :converged, :max_iter or :diverged,
  • fcalls: number of objective/constraint evaluations performed,
  • iterations: number of interior-point iterations run.

NonconvexInteriorPoint.barrier_gradient! — Method
barrier_gradient!(g, m, x, mu, opts)

Gradient ∇φ_μ(x) of the barrier objective, assembled from adjoints (transposed-Jacobian-vector products): the vector-inequality barrier terms contribute J_c'(μ/s), which requires only the pullback/adjoint of each constraint function — the Jacobian is never materialized. This keeps the gradient path first-order-compatible (usable without any second-order machinery) and label-aware (matrix-free-labeled constraints contribute through their adjoint exactly as in the KKT operator).

At an infeasible point (before the strict-barrier mode is established) the smooth C² extension has no closed-form adjoint assembly, so the scalar closure is differentiated there instead (also reverse-mode).

NonconvexInteriorPoint.barrier_objective — Method
barrier_objective(m::IPMModel, x, mu, opts::IPMOptions)

The barrier objective φ_μ(x) = f(x) + μ·(scalar and set barrier terms) of IPMAlg: inequalities and box bounds contribute μ-scaled scalar barriers, set constraints (PSD cones) their sd_type barrier. Returns Inf on a violated constraint when the iterate is in the feasible regime (so line searches reject infeasible points); infeasible starts use a smooth C¹ extension of the log barrier.

NonconvexInteriorPoint.barrier_objective_ext — Method
barrier_objective_ext(m, x, mu, opts)

Smoothly-extended variant of barrier_objective for custom inner optimizers that cannot handle Inf values: feasible constraints get the strict log barrier, near-boundary values the C¹ linear extension, and violated values a hard quadratic penalty (so the inner solve cannot escape to infeasibility). PSD violations are still rejected with Inf.

NonconvexInteriorPoint.barrier_value — Method
barrier_value(set, v)

Barrier value of the set at the (matrix) value v. Fallback: unsupported.

NonconvexInteriorPoint.barrier_value_c — Method
barrier_value_c(c, set, x, mode, opts)

Barrier value φ_S(c(x)) of the set constraint. Returns -Inf for a violated constraint (strict interiority is required). The only barrier set constraints in the current model conversion are PSDCones (handled below); other sets are converted to classical constraints.

NonconvexInteriorPoint.hutchinson_trace — Method
hutchinson_trace(f!, n, k, rng)

Estimate tr(A) where f!(y, x) computes y = A * x in place, using k Rademacher probes.

NonconvexInteriorPoint.hutchpp_trace — Method
hutchpp_trace(f!, n, k, rng)

Estimate tr(A) with the Hutch++ (Nyström + Hutchinson) estimator using k sketch columns and k residual probes.

NonconvexInteriorPoint.hvp — Method
hvp(f, x, v)

Hessian-vector product ∇²f(x) v of the scalar-valued function f, computed with DifferentiationInterface's second-order machinery (forward-over-reverse, SecondOrder(AutoForwardDiff(), backend)) using NonconvexCore's configured AD backend (AutoZygote by default). Falls back to the dense Hessian (and then to zeros) when the second-order machinery fails.

NonconvexInteriorPoint.jacprod — Method
jacprod(f, x, v)

Jacobian-vector product J_f(x) v of the vector-valued function f. DifferentiationInterface's Zygote backend does not support pushforwards (reverse-mode only), so this stays on Zygote's own forward mode — the only JVP available without materializing the dense Jacobian.

NonconvexInteriorPoint.jtprod — Method
jtprod(f, x, w)

Transposed-Jacobian-vector product J_f(x)' w of the vector-valued function f, computed through NonconvexCore's reverse-mode wrapper (which handles nothing gradients of constant functions).
