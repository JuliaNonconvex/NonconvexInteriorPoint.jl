NonconvexInteriorPoint

Description

NonconvexInteriorPoint.jl provides IPMAlg, a native primal barrier interior-point method for smooth, generally nonconvex nonlinear programs in the JuliaNonconvex ecosystem. It supports box bounds, inequalities, equalities, native linear constraints with cached constant Jacobians, and — through NonconvexCore's set constraints — generalized inequalities including semidefinite cones, via a barrier-oracle protocol (see Set constraints). Inequalities and set constraints enter the barrier with adjoint-only gradients (no Jacobians are materialized); only the equality constraints contribute Jacobians to the KKT system. A slacks = true option switches to the Ipopt-style slacked formulation.

A distinguishing feature is the per-constraint selection of evaluation strategies through NonconvexCore's label (flags) mechanism: constraints can be evaluated densely, matrix-free (implicit products, iterative solves), or with randomized trace estimation (Hutchinson, Hutch++, stochastic Lanczos quadrature, and more) for log-determinant barriers. This enables large sparse SDP-constrained problems (e.g. buckling-constrained design) without ever materializing dense matrices. See Matrix-free and trace-estimated evaluation.

The algorithm follows the Ipopt/MadNLP/Uno lineage: regularized (inertia-corrected) KKT systems solved densely or matrix-free with Krylov methods, backtracking on an exact-penalty merit, an adaptive barrier update, per-constraint barrier selection with pluggable barrier types, and an optional inner optimizer for the barrier subproblems. The design document is DESIGN.md.

See Quick start for the first steps, Options for the full option reference, Set constraints for barrier oracles, Matrix-free and trace-estimated evaluation for the per-constraint evaluation modes, Result for the returned result fields, Theory for the algorithmic background, the buckling-constrained example for a worked nonconvex SDP, and Docstrings for the API reference.
